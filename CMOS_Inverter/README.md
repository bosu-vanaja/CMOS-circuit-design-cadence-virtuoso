# CMOS Inverter Design & Simulation

## Overview
Designed and simulated a CMOS inverter using Cadence Virtuoso at transistor level. Created schematic, testbench, and transient simulation setup to analyze switching characteristics and output response.

## Implementation
- Designed CMOS inverter using PMOS and NMOS transistors
- Created testbench with pulse input source and DC supply
- Simulated input and output waveforms using transient analysis

## Analysis Performed
- Transient Analysis
- Switching Behavior Analysis
- Output Response Verification

## Tools Used
- Cadence Virtuoso
