# SRAM Design & Simulation

## Overview
Designed and simulated an SRAM circuit using Cadence Virtuoso to study memory operation and transistor-level behavior.

## Implementation
- Designed SRAM schematic
- Configured testbench for simulation
- Verified functionality using transient analysis

## Analysis Performed
- Transient Analysis
- Output Response Verification
- Stability Analysis

## Tools Used
- Cadence Virtuoso
