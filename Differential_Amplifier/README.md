# Differential Amplifier Design & Simulation

## Overview
Designed and simulated a CMOS differential amplifier using Cadence Virtuoso to analyze differential input behavior and output response.

## Implementation
- Designed transistor-level differential amplifier circuit
- Created simulation setup with differential input signals
- Verified amplifier response using transient analysis

## Analysis Performed
- Transient Analysis
- Output Response Analysis
- Differential Signal Verification

## Tools Used
- Cadence Virtuoso
