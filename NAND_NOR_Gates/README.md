# NAND/NOR Gates Design & Simulation

## Overview
Designed and simulated CMOS NAND and NOR gates using Cadence Virtuoso. Created transistor-level schematics and verified logic operation through transient waveform analysis.

## Implementation
- Designed CMOS NAND and NOR gates using PMOS and NMOS networks
- Created testbench configurations with pulse inputs
- Verified logic functionality using transient simulations

## Analysis Performed
- Transient Analysis
- Logic Verification
- Output Waveform Analysis

## Tools Used
- Cadence Virtuoso
